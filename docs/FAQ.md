# 常见问题 FAQ

版本: 1.0.0  
最后更新: 2026-01-26

---

## 端口如何修改？
- 前端端口：在启动参数或 Streamlit 配置中调整（默认 8501）
- 后端端口：在 `backend/main.py` 启动或 `backend/config.py` 中调整（默认 8000）

## 如何使用GPU加速嵌入？
- 在 `.env` 或 `backend/config.py` 中将设备设置为 `cuda`
- 确保已安装对应版本的 CUDA 和驱动

## 上传提示“409 冲突（重复文件）”？
- 系统基于 MD5 做去重，同内容文件会被判定为重复
- 解决：修改文件内容或跳过重复上传

## 向量库路径如何变更？
- 修改 `config.py` 中 Chroma 持久化目录（默认 `indexes/`）
- 变更后需执行“重建全部索引”保持一致性

## 索引失败如何处理？
- 在“索引管理”页面对该文件执行“重新索引”
- 检查日志 `logs/`，确认是否为文件格式或解析错误

## 失败的PDF/Docx解析怎么办？
- 确保安装 `PyMuPDF` 与 `python-docx`
- 尝试将文档另存为兼容格式（如 .pdf 为“可提取文本”）

## 如何提升检索准确度？
- 调整分块大小和重叠率，使片段更语义完整
- 增加 Top-K（如 5-10）提高召回覆盖
- 启用 LLM 增强获得更自然与上下文丰富的回答

## API 如何快速调用？
- 打开 `http://localhost:8000/docs` 交互式文档
- 参考 `docs/API_DOCUMENTATION.md` 获取请求与响应示例

## 我可以导入已有文档库吗？
- 将文件放入 `data/documents/` 或 `data/code/`，再在前端执行“重建全部索引”

## 备份与恢复如何进行？
- 备份 MySQL 数据与 `indexes/` 目录
- 恢复后执行“重建全部索引”以重建向量数据
