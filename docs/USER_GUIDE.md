# 用户使用指南

版本: 1.0.0  
最后更新: 2026-01-26

---

## 概述

本指南面向普通用户，帮助快速完成安装、启动、文件上传与索引、智能问答、以及常见管理操作。无需编程基础即可使用。

---

## 安装与启动

### Windows 一键启动
1. 双击 `start_all.bat`
2. 首次运行会自动创建虚拟环境并安装依赖（需联网）
3. 启动完成后将自动打开浏览器并进入前端页面

### Linux/macOS 一键启动
```bash
chmod +x start_all.sh
./start_all.sh
```

### 访问地址
- 前端界面: http://localhost:8501
- 后端API文档: http://localhost:8000/docs

---

## 上传与索引

### 支持的文件类型
- 文档: .txt, .pdf, .docx, .md, .html
- 代码: .py, .js, .java, .cpp, .go, .rs, .ts 等

### 上传步骤
1. 在“文件管理”页选择文件或文件夹
2. 点击“开始上传”
3. 系统自动保存文件并入库，随后后台自动进行索引

### 索引状态说明
- 已索引: 可参与检索与问答
- 索引中: 正在处理，请稍候
- 失败: 可尝试“重新索引”操作
- 未索引: 上传成功但未触发索引（可手动重建）

---

## 智能问答

1. 打开“智能问答”页面
2. 输入问题（建议使用自然语言）
3. 系统召回相关片段，并生成简洁回答
4. 界面将展示参考来源与相似度分数

提示: 默认关闭LLM增强（USE_LLM_QA=False），可在配置中启用以获得更自然的答案。

---

## 文件管理

- 列表查看：展示文件名称、类型、大小、上传时间、索引状态
- 删除文件：支持单个或批量删除（索引会同步清理）
- 详情查看：展示文件元信息及索引片段数
- 重新索引：当索引失败或配置调整后，可对指定文件重建索引

---

## 配置常用项

在 `backend/config.py` 或环境变量中可调整：
- 嵌入模型与设备（CPU/GPU）
- 文本分块大小与重叠率
- Chroma 持久化路径（`indexes/`）
- MySQL 连接参数

---

## 常见操作

- 清空所有索引：在“索引管理”页使用“重建全部索引”（会清空向量库后重索引）
- 查询相似片段：在“索引管理”页使用“相似检索”，输入查询文本
- 查看统计信息：在“文件管理/索引管理”页均可查看总数、索引率、向量数
