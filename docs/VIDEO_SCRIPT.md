# 视频演示脚本（本地知识库系统）

版本: 1.0.0  
最后更新: 2026-01-26

---

## 目标与时长
- 目标：演示系统的安装启动、文件上传与索引、智能问答、索引管理与检索、故障排查入口。
- 预计时长：5–7 分钟。

---

## 大纲
1. 开场与简介（20秒）
2. 安装与启动（40秒）
3. 上传与索引（90秒）
4. 智能问答（80秒）
5. 索引管理与检索（100秒）
6. 用户文档与排障（60秒）
7. 总结与结束（20秒）

---

## 详细脚本

### 1) 开场与简介（旁白 20秒）
- 画面：项目首页（Streamlit 前端），标题“本地知识库系统”。
- 旁白：
  - “今天我们演示一个基于 Python 的本地知识库系统，支持文件上传、向量索引、语义检索与问答。”

### 2) 安装与启动（讲解 + 操作 40秒）
- 画面：命令行窗口与浏览器。
- 操作：
  - Windows 双击 `start_all.bat`；或在 Linux/macOS 运行：
    ```bash
    chmod +x start_all.sh
    ./start_all.sh
    ```
  - 展示浏览器自动打开：http://localhost:8501。
- 旁白：简述一键脚本会创建虚拟环境、安装依赖、启动后端与前端。

### 3) 上传与索引（讲解 + 操作 90秒）
- 画面：前端“文件管理”页面。
- 操作：
  - 选择两个示例文件（例如 `python_intro.txt` 和一个中等大小文档）。
  - 点击“开始上传”，展示进度与成功提示。
  - 展示文件列表中的索引状态从“pending/索引中”到“已索引”。
- 旁白：
  - “系统自动解析文本并分块，使用嵌入模型向量化，持久化到 Chroma 向量库。”

### 4) 智能问答（讲解 + 操作 80秒）
- 画面：前端“智能问答”页面。
- 操作：
  - 输入问题：“这个系统可以做什么？”或“如何上传文件？”
  - 展示回答与参考来源、相似度。
  - 可选：勾选“使用高级生成（LLM）”，演示失败回退或更自然回答（视环境而定）。
- 旁白：
  - “问答基于检索到的相关片段进行生成，默认关闭 LLM 增强，可在配置中开启。”

### 5) 索引管理与检索（讲解 + 操作 100秒）
- 画面：前端“索引管理”页面。
- 操作：
  - 展示总体状态卡片：总文件数、已索引、待索引、向量数等。
  - 选择一个文件执行“重新索引”。
  - 在“语义搜索测试”输入查询文本，展示结果内容、来源、分块号与相似度。
- 旁白：
  - “支持重建与删除索引，语义搜索可以快速定位相关片段。”

### 6) 用户文档与排障（讲解 + 操作 60秒）
- 画面：前端侧边栏选择“📖 用户文档”。
- 操作：
  - 从下拉框选择“使用指南”“FAQ”“快速上手”等文档，展示内嵌渲染效果。
  - 简要打开“故障排查”文档，说明常见问题与解决路径。
- 旁白：
  - “文档入口集成在前端，便于快速查阅。”

### 7) 总结与结束（旁白 20秒）
- 画面：回到首页或“智能问答”页面。
- 旁白：
  - “本地知识库系统提供端到端的检索与问答能力，轻量易用，适合个人与团队知识管理。”

## 准备素材建议
- 小/中等/较大三个示例文件（docs/data 中已含示例）。
- 浏览器与终端并排展示的录屏布局。
- 网络环境良好（首次安装需联网）。

---

## 录制注意事项
- 指针移动与点击动作保持简洁清晰。
- 旁白语速适中，屏幕变化与旁白同步。
- 失败情况（如LLM下载失败）可自然说明并展示模板回退。
